# Linux Lab

System administration scripts and tools built during CompTIA Linux+ (XK0-006) certification prep.

## sysinfo.sh

A system health check script that reports:
- Hostname, user, date, uptime
- Disk usage
- Running process count
- Network configuration
- Top 5 CPU-consuming processes
- Logged in users

### Usage

```bash
chmod 755 sysinfo.sh
./sysinfo.sh
```
